# Dormilin · Muebles y Colchones

Landing page premium para **Dormilin | Muebles y Colchones** — fabricantes de muebles de pino y colchones en Morón, zona oeste del Gran Buenos Aires.

## Stack
Sitio estático, sin dependencias ni build. HTML + CSS + JavaScript vanilla.

- `index.html` — página completa
- `styles.css` — sistema visual derivado del logo (coral · gris · ámbar)
- `script.js` — menú mobile, header sticky, animaciones de reveal, links de WhatsApp
- `assets/` — logo, imágenes de producto e imagen Open Graph
